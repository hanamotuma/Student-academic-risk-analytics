# User Guide

## Running the App
1. Open RStudio.
2. Load `app.R`.
3. Click "Run App".

## Modules
- **Dashboard**: KPI cards and distribution.
- **Students**: Search, filter, view records.
- **Performance**: Subject comparison, attendance vs score.
- **Risk**: Risk distribution, high-risk list.
- **Reports**: Download Excel reports.

## Data
Replace `data/sample/students.csv` with your own dataset (same columns).
